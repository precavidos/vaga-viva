Movimento.

Os seis componentes de movimento do item 3.3 do DESIGN.md, em vv-motion.css e vv-motion.js. Com movimento reduzido, cada um aparece parado no estado final.

Matriz de pontos

Uma matriz 4×4 por etapa de espera real, num ciclo de 1,6 s. O HTML escreve só o elemento vazio; o JS põe os 16 pontos.

scan

Varredura em amarelo, linha por linha. Ler a vaga, carregar o painel.

data-dot-matrix="scan"

wave

Onda diagonal em roxo. Montar o plano, o revisor.

data-dot-matrix="wave"

flip

Coral vira verde, um ponto por vez. Criar o repositório.

data-dot-matrix="flip"

Linha de status

Matriz, rótulo no gerúndio e cronômetro. done() fecha a espera com sucesso, stop() a interrompe; os dois param o cronômetro e a matriz.

VVMotion.statusLine(el, 'Montando o plano') → { done(), stop() }
