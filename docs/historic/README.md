# Histórico de specs e planos

Estes são os desenhos (`specs/`) e os planos de implementação (`plans/`) escritos entre 11 e 17/11/2026 com o plugin superpowers. Todos já foram executados, e ficam aqui como registro das decisões.

- As instruções para agentes no topo dos planos (por exemplo, `superpowers:subagent-driven-development`) estão obsoletas. O plugin não é mais usado.
- Specs e tarefas novas viram issues no GitHub. Veja `docs/agents/issue-tracker.md`.
- Os caminhos `.superpowers/brainstorm/...` citados em alguns desenhos apontavam para arquivos locais que nunca entraram no repositório.
